# Connecteurs (adapté à notre configuration)

Les compétences issues d'anthropics/knowledge-work-plugins écrivent `~~catégorie` pour désigner un outil connecté.
Correspondances chez nous :

| Placeholder | Chez nous |
|---|---|
| `~~data warehouse`, `~~spreadsheet` | Google Sheets (connecteur claude.ai), sinon fichiers CSV/JSON exportés des applis |
| `~~project tracker` | `TASKS.md` dans le dépôt concerné + issues GitHub de l'organisation Projets-Antoine-Calabrese |
| `~~knowledge base`, `~~docs` | Claude Docs (connecteur claude.ai) et les `docs/` des dépôts |
| `~~email` | Gmail (connecteur claude.ai) |
| `~~chat`, `~~product analytics`, `~~notebook`, `~~design` | Non connectés — travailler à partir des données fournies dans la conversation |
